# Contributing to BleuNova AI Agent

Thank you for considering contributing to BleuNova!  
We welcome bug reports, feature requests, documentation improvements, new skills, and code contributions.

## How to Contribute

1. **Found a bug or want a feature?**  
   Open an issue using one of the templates.

2. **Want to submit code or docs?**  
   - Fork the repo  
   - Create a branch: `git checkout -b feature/amazing-feature` or `fix/bug-123`  
   - Make your changes  
   - Add tests if applicable (we run pytest in CI)  
   - Format code: `black .`  
   - Commit with conventional style: `feat: add new skill`, `fix: resolve sandbox timeout`, `docs: update readme`  
   - Push and open a Pull Request

## Pull Request Guidelines

- Title: Clear and prefixed (feat/fix/docs/refactor/chore/test/style)
- Description: Explain what + why + how
- Link related issue if any
- Include screenshots / before-after for UI changes
- Pass all CI checks

## Skill Contributions

We’d love new skills!  
Please submit them via PR to `src/integrations/` or propose them in an issue first.

## Code of Conduct

Be kind, respectful, and constructive. We follow the Contributor Covenant (v2.1).
