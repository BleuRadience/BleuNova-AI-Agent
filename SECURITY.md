# Security Policy

## Supported Versions

We actively support the latest release on the main branch.

## Reporting a Vulnerability

Please **do not** open public issues for security problems.  
Instead, email security@bleunova.ai (or DM @BleuRadience on X) with:

- Description of the vulnerability
- Steps to reproduce
- Potential impact
- Suggested fix (if you have one)

We will acknowledge receipt within 48 hours and aim to provide an update (including timeline for fix) within 7 days.

## Preferred Disclosure Timeline

We follow coordinated disclosure:  
- We fix critical issues within 30 days  
- We publicly disclose after patches are released (usually 90 days max)

Thank you for helping keep BleuNova safe.
